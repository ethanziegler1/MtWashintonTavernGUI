# Mt. Washington Tavern DBMS

A desktop database management system built in Java for Mt. Washington Tavern, designed to manage restaurant operations including staff, orders, and menu items through an intuitive GUI.

## 🧩 Overview

This application allows restaurant staff and managers to:
- Insert, delete, and update records for orders, employees, and menu items
- Search and view database entries with validated input
- Maintain data integrity through normalized schema design
- Easily navigate the system via a responsive Java Swing interface

## 🛠️ Technologies Used

- **Java** – Core programming language
- **Swing** – GUI toolkit for the desktop interface
- **MySQL** – Relational database backend
- **JDBC** – Java Database Connectivity for MySQL integration
- **Agile** – Developed in a team using Agile methodology with biweekly sprints
  
## 🧠 Lessons Learned

- Practiced designing/normalizing relational schemas
- Improved Java Swing UI design skils
- Gained experience integrating Java with MySQL via JDBC
- Learned to coordinate team efforts through Agile sprint cycles
